## Group Project

## AI-Enabled Corporate Finance Decision Dashboard or App

## 1. Project Overview

Each group must design an AI-enabled corporate finance dashboard or Application that analyses a realistic financial decision.

The project must combine:

- Corporate finance calculations

- Financial data analysis

- Artificial intelligence features

- Scenario analysis

- Dashboard visualization

- Managerial recommendations

## 2. Project Objective

The objective is to demonstrate how artificial intelligence can support corporate finance decisions by:

- Automating financial calculations

- Analysing financial information

- Forecasting cash flows

- Comparing financial alternatives

- Identifying financial risks

- Producing management recommendations

- Presenting results through a clear dashboard
